# Copilot Instructions

This project follows a strict data-driven architecture.

Rules:

1. Never hardcode stars, sectors, routes, resources, or rules.
2. Load gameplay data from JSON files.
3. Keep game logic independent from UI.
4. Prefer composition over inheritance.
5. Favor simple, readable GDScript.
6. Build for maintainability rather than optimization.
7. Every feature should support future scenarios.
8. The original 4000 A.D. scenario is only one scenario.
9. Separate rendering logic from gameplay logic.
10. Use services and domain objects before adding UI code.
